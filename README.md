## Experiencia destacada

```text
Topaz Colombia S.A.                                          2026 - Actualidad
Arquitectura multiagente · MCP · AWS Lambda · Microsoft Graph · Azure DevOps
```

- Diseñé e implementé sistemas multiagente con el protocolo **Model Context Protocol (MCP)**.
- Construí servicios serverless en **AWS Lambda**, integrados con API Gateway, DynamoDB, EventBridge, SQS y Secrets Manager.
- Desarrollé agentes para Outlook, Azure DevOps, QA e Historias de Usuario.
- Automatizé la renovación de suscripciones a webhooks de Microsoft Graph.
- Implementé el **MCP JAZZ** con Cliente y Servidor, Docker y despliegue en infraestructura interna.
- Desarrollé un Add-in de Excel con arquitectura hexagonal, autenticación Microsoft Entra ID y procesamiento conversacional asíncrono.
- Creé validaciones con casos golden y no-golden para garantizar la integridad de metadatos.
- Soporté y restauré incidentes de producción en el proyecto CSR sobre Microsoft Graph API.
